# CUDA runtime pins for jax 0.4.30.
#
# docs/TASK.md pins jax but not the nvidia-* CUDA wheels, and
# `jax-cuda12-plugin[with_cuda]==0.4.30` declares only LOWER bounds on them
# (nvidia-cudnn-cu12>=9.1,<10.0, nvidia-cublas-cu12>=12.1.3.1, ...). A resolver
# run today therefore installs the CUDA 12.9 family and cuDNN 9.24 against a
# jaxlib built for CUDA ~12.3-12.5, which:
#
#   * segfaults on the first cuBLAS call (ABI mismatch), and
#   * fails to compile at all when ptxas (12.9) is newer than the driver, e.g.
#     "The NVIDIA driver's CUDA version is 12.8 which is older than the ptxas
#      CUDA version (12.9.86)".
#
# Bounding the family at CUDA 12.4 / cuDNN 9.1 keeps us contemporary with what
# jax 0.4.30 (July 2024) was built and tested against, and safely below any
# driver from CUDA 12.4 onwards. Upper bounds rather than exact pins so the
# resolver can still pick the newest patch release in each series.
#
# Note the offset versioning: for CUDA 12.4, cufft is 11.2.x, cusolver 11.6.x
# and cusparse 12.3.x - the bounds below are aligned to that, not to "12.4".
nvidia-cublas-cu12<12.5
nvidia-cuda-cupti-cu12<12.5
nvidia-cuda-nvcc-cu12<12.5
nvidia-cuda-nvrtc-cu12<12.5
nvidia-cuda-runtime-cu12<12.5
nvidia-cudnn-cu12<9.2
nvidia-cufft-cu12<11.3
nvidia-cusolver-cu12<11.7
nvidia-cusparse-cu12<12.4
nvidia-nvjitlink-cu12<12.5
